# Запуск на новом ПК

Сайт = FastAPI-сервер (`server.py`). До публичного запуска он закрыт
заглушкой-замком: всё видно только админу по логину и паролю.

## 1. Поставить Python
- **Python 3.11+** с https://python.org (на установке отметить галочку
  **«Add Python to PATH»**).
- Желательно **Google Chrome** — нужен модулю сбора токенов Wildberries
  (без него сервер запустится, но парсинг WB деградирует).

## 2. Установить зависимости
Открыть терминал в папке с `server.py`:

```bash
python -m venv .venv
```

```bash
pip install -r requirements.txt
```

## 3. Настроить конфиг
```bash
cp config.example.json config.json
```

Заполнить ключи LLM-провайдера и генератора изображений. Минимально нужны:

| Ключ | Зачем |
|---|---|
| `claude_api_key` / `claude_base_url` | текст, дизайн пака, гейты качества |
| `openai_image_api_key` или `fastgen_api_key` | рендер изображений |
| `oauth.google` / `oauth.yandex` | вход через соцсети (опционально) |
| `smtp.*` | письма и сброс пароля (опционально) |

## 4. Запустить сервер
```bash
python server.py
```

В консоли появится строка вида `Starting API on http://127.0.0.1:8002`
(порт подбирается автоматически из диапазона 8000–8019).

## 5. Войти
Открыть адрес из консоли. Появится экран **«Сайт закрыт»** → ввести логин
и пароль замка. В файлах пароль не хранится — только PBKDF2-хеш и соль
в `config.json`, логин задаётся там же в блоке `site_gate`.

После входа ставится cookie на 7 дней.

## 6. Открыть сайт для всех
В `config.json`:

```json
"site_gate": { "enabled": false }
```

и перезапустить сервер.

> В проде секреты лучше держать в переменных окружения
> `WBN_GATE_LOGIN / WBN_GATE_HASH / WBN_GATE_SALT / WBN_GATE_SECRET /
> WBN_GATE_ENABLED` — они приоритетнее `config.json`.

## Полезное
- Чистый старт БД: удалить `data/wbnator.db*` — база пересоздастся сама.
- За nginx с HTTPS cookie замка автоматически становится `Secure`.

## ⚠️ Про безопасность
`config.json` содержит боевые API-ключи и секрет замка. Он в `.gitignore`
и не должен попадать в репозиторий или в публичные архивы.
