# Гайд: от нуля до приложения на эмуляторе и на телефоне

Этот гайд — пошагово. Делай по порядку, **не пропускай**.

---

## Часть 1. Установка Android Studio (один раз в жизни, 30-40 минут)

### 1.1 Скачивание

Иди на <https://developer.android.com/studio> → **Download Android Studio**. Скачается `.exe` на ~1.2 ГБ.

### 1.2 Установка

Запусти инсталлер. Везде **Next**. В конце оставь галочку **Start Android Studio**.

### 1.3 Welcome-визард при первом запуске

При первом старте Android Studio покажет визард на 5 экранов. **Внимание, тут есть ловушки**:

| Экран | Что выбрать |
|---|---|
| Import Settings | **Do not import settings** |
| Install Type | **Standard** ✅ (НЕ Custom) |
| Select UI Theme | На вкус. Darcula — тёмная, IntelliJ Light — светлая |
| Verify Settings | **Next** (увидишь список: SDK Platform 34, Build Tools, Platform-Tools, Emulator, Android 14 system image — всё правильно) |
| License Agreement | Прими **все** лицензии (нажми на каждую слева → Accept справа), потом Finish |

После Finish пойдёт скачка SDK — **~3 ГБ, минут 15-25** в зависимости от интернета. Не закрывай окно.

Когда увидишь **Welcome to Android Studio** с кнопками `New Project / Open / Get from VCS` — установка готова.

## Часть 2. Создание эмулятора (5 минут)

В Welcome-окне Android Studio:

1. **More Actions** (выпадающая стрелка справа сверху) → **Virtual Device Manager**.
   Или после открытия проекта: **Tools → Device Manager**.

2. Кнопка **➕ Create Device** (или знак плюса).

3. **Phone → Pixel 7** → Next.

4. **System Image**: выбери ряд с `UpsideDownCake | API 34 | Android 14.0 | Google Play`.
   Если справа от ряда написано **Download** — нажми, скачается ~1.5 ГБ. Дождись. Потом Next.

5. **AVD Name**: оставь как есть (`Pixel_7_API_34`). **Finish**.

Эмулятор появится в списке. Запускать его сейчас не надо — стартер сам поднимет.

## Часть 3. Открытие проекта (1 минута)

В Welcome-окне Android Studio: **Open** → выбери папку `C:\Users\Alex\WBnator_android` → **OK**.

Android Studio начнёт **Gradle Sync** — внизу будет полоса и буквы. Первый раз — 3-5 минут (качает Gradle 8.7 и зависимости).

Когда внизу написано **Gradle sync finished** — готово.

> ⚠️ Если sync упадёт с ошибкой про SDK — справа сверху открой **File → Project Structure → SDK Location** и убедись что путь к SDK не пустой (обычно `C:\Users\Alex\AppData\Local\Android\Sdk`). Закрой ОК.

## Часть 4. Запуск

### Вариант А: из Android Studio (рекомендую первый раз)

1. Сверху рядом с зелёной стрелкой ▶ — выпадающий список устройств. Выбери `Pixel 7 API 34`.
2. Нажми ▶ (или **Shift+F10**).
3. Эмулятор запустится (первый старт — до минуты).
4. Приложение соберётся, установится, откроется.

Должен увидеть splash с твоим лого на лавандовом фоне, потом — твой сайт `kartochka.ai` в полноэкранном окне.

### Вариант Б: одной кнопкой через стартер

После того как сделал шаги 1-3 (Android Studio открыта хотя бы раз и сделал Sync):

```
start.bat
```

Стартер сам:
- найдёт SDK,
- поднимет эмулятор (первый из списка AVD),
- соберёт APK,
- установит,
- запустит приложение.

Окно эмулятора появится отдельно. Логи стартера в консоли.

### Вариант В: на реальном телефоне

Если у тебя/друга есть Android-телефон:

1. На телефоне: **Настройки → О телефоне → 7 раз тапни «Номер сборки»** → включится Режим разработчика.
2. **Настройки → Для разработчиков → Отладка по USB** → включить.
3. Подключи телефон USB-кабелем, **разреши отладку** в попапе на телефоне.
4. В Android Studio в выпадающем списке устройств появится твой телефон → выбери его → ▶.

Или через `start.bat` — он автоматически найдёт подключённое устройство и пропустит эмулятор.

## Часть 5. Что проверять при тестировании

Если на сайте всё работает в Chrome — в эмуляторе оно тоже работает (тот же Chromium). Проверяй только нативные штуки:

- [ ] **Splash**: при запуске виден лавандовый экран с лого, без белой вспышки.
- [ ] **Статус-бар**: фиолетовый (`#4C29D3`), иконки белые.
- [ ] **Иконка лаунчера**: твой лого на градиенте фиолетового.
- [ ] **Назад (системная кнопка / жест)**: ходит по истории WebView, на корне закрывает приложение.
- [ ] **Загрузка фото**: тапни в сайте «Загрузить фото» → должен открыться системный пикер с опцией «Камера». Снять кадр или выбрать из галереи → фото уходит в `/api/upload`.
- [ ] **SSE прогресс**: запусти генерацию пакета карточек, прогресс должен капать в реальном времени (через `/api/generation/{gid}/stream`).
- [ ] **Cookie**: залогинься, закрой приложение, открой заново — ты всё ещё залогинен.
- [ ] **Внешние ссылки**: тап по `t.me/kartochka_ai`, `vk.com/...` в футере — открывается в Chrome, **не** подменяет контент WebView.

## Часть 6. Сборка релизного APK для Google Play

Когда дойдёт до релиза:

```bat
keytool -genkey -v -keystore kartochka-release.keystore -alias kartochka -keyalg RSA -keysize 2048 -validity 10000
```

(Пароль и данные сохрани в надёжное место, без них следующие версии не выпустишь.)

Дальше в `app/build.gradle.kts` добавь `signingConfigs.release` (пример в [README.md](README.md)) и собирай:

```bat
gradlew assembleRelease
```

APK будет в `app\build\outputs\apk\release\app-release.apk`.

Для Play Store нужен **AAB** (App Bundle) вместо APK:

```bat
gradlew bundleRelease
```

→ `app\build\outputs\bundle\release\app-release.aab`.

## Часть 7. Частые проблемы

**Gradle sync падает с `SDK location not found`**
→ `File → Project Structure → SDK Location` → задай путь к SDK (обычно `%LOCALAPPDATA%\Android\Sdk`).

**Эмулятор не стартует / висит на чёрном экране**
→ Включи аппаратную виртуализацию в BIOS (Intel VT-x / AMD-V). Без неё эмулятор работает на голом CPU и тормозит как в аду.

**Эмулятор стартует, но WebView показывает белый экран**
→ Эмулятор пошёл за `https://kartochka.ai`, но интернет в AVD отвалился. Проверь: `Tools → AVD → Cold Boot Now`. Или внутри эмулятора открой Chrome и убедись что Wi-Fi есть.

**Сайт грузится, но фото не загружается / камера не открывается**
→ При первом тапе по «Загрузить фото» Android попросит разрешение на камеру. Если случайно отказал — `Настройки приложения → Разрешения → Камера → Разрешить`.

**Тестирую на локальном `127.0.0.1:8000` — в эмуляторе сайт не открывается**
→ Внутри эмулятора `127.0.0.1` означает сам эмулятор, не твой ПК. Поменяй `SITE_URL` в `MainActivity.kt:292` на `http://10.0.2.2:8000/` (магический алиас на хост). `network_security_config.xml` уже разрешает cleartext к `10.0.2.2`.

**Хочу видеть логи WebView**
→ В консоли где запущен `start.bat`:
```
%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe logcat -s chromium:* WebView:* kartochka.app:*
```
Или через AS: **View → Tool Windows → Logcat**.

**Открыть DevTools для отладки WebView (как F12 в Chrome)**
→ На ПК открой Chrome и набери в адресной строке `chrome://inspect/#devices`. Эмулятор/телефон с подключённой отладкой покажет твой WebView. Нажми **inspect** → откроется DevTools этого WebView. Жизнь без этого невозможна, запомни.

## Что трогать, что не трогать

| Трогать | Не трогать (без причины) |
|---|---|
| `MainActivity.kt:SITE_URL` — поменять URL | `KartochkaApp.kt` — multi-process WebView setup |
| `res/values/colors.xml` — цвета | `mixedContentMode = NEVER_ALLOW` в WebView |
| `res/drawable/splash_logo.png` — лого на splash | `app/build.gradle.kts` versionCode/Name — менять только при релизе |
| `res/mipmap-xxxhdpi/ic_launcher*.png` — иконка | `proguard-rules.pro` без понимания |

В принципе всё. Если на каком-то шаге застрял — кидай скрин ошибки.
