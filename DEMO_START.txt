Быстрый просмотр без API-ключей:
python -m venv .venv
Windows: .venv\Scripts\activate
macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements-demo.txt
python demo.py

Готовый результат: http://127.0.0.1:8082/?demo=result
Пошаговый сценарий: http://127.0.0.1:8082
Нажмите «Посмотреть пример · бесплатно» в первом блоке.
Показывается сохранённый сценарий с товаром, конкурентами, четырьмя карточками и описанием.
Новая генерация, вход и платежи в этом демо не выполняются.

Демо запускается независимо от полного приложения, без ключей и базы данных.
Обычный backend site/server.py в исходном коммите 29c5df1 не запускается:
отсутствуют импортируемые wb_token_pool и wb_smart_client.
Этот demo.py независим от backend и не исправляет его внешние интеграции.
